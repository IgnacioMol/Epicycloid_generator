# Epicycloid Generator — Project Overview

## What this is

A web application built as a **TFG (Trabajo de Fin de Grado)** for university. It generates visual compositions based on **epicycloid orbital patterns** — mathematical curves produced by tracing a point on a circle rolling around the outside (or inside) of another circle.

The app combines Angular for UI/state management and p5.js for real-time canvas rendering.

## Goal

Allow users to interactively manipulate mathematical parameters (radii, angular speeds, phase, color, stroke) and watch the resulting curve draw itself in real time. Think of it as a spirograph simulator with full parametric control.

## Tech stack

| Layer | Technology |
|---|---|
| Framework | Angular 21.1 (standalone components) |
| Graphics | p5.js 2.2.3 |
| State | RxJS BehaviorSubject (PatternService) |
| Styling | Bootstrap (note: `package.json` has typo `"boostrap"` — the real package is `bootstrap`) |
| Testing | Vitest |
| Deployment | Vercel |

## Two visualization modes (RF8)

1. **Epicicloidal curve mode** — classical epicycloid/hypotrochoid tracing
2. **Line intersection mode** — pattern generated by drawing intersecting lines at angular intervals (Schotter-style aesthetic)

## Deployment target

Vercel (public hosting, no backend required).
